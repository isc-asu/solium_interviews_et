## Current analyses

- [Interviews](updated/interviews.Rmd): farm and abattoir interview analysis.
- [Literature review](updated/literature_review.Rmd): publication summaries and locality map.
- [FAOSTAT](updated/faostat.Rmd): livestock stocks and meat production.

All current source data are in **[updated/data/](updated/data/)**.
Rebuilt summary tables are in **[updated/results/](updated/results/)**.
The interview questionnaire is in **[updated/docs/](updated/docs/)**.

**Run the notebooks with `updated/` as the working directory.**
See [the updated version's instructions](updated/README.md) for packages and
commands. There are no active code or CSV files at the repository root.

The raw interview CSVs are identical across the archived and updated versions;
the current interview analysis includes revised cleaning and summaries.
